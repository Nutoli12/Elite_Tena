Test Configuration

Frontend URL: http://localhost:5174
Backend URL: http://localhost:3004
Expected Behavior: Refresh should redirect to landing page (/) for unauthenticated users

Manual Test Instructions

  1. Test 1 - Unauthenticated User:
    • Open http://localhost:5174
    • You should see the landing page with "The Future of Healthcare" title
    • Refresh the page (F5 or Ctrl+R)
    • ✅ PASS: Should stay on landing page
    • ❌ FAIL: If redirected elsewhere
  2. Test 2 - Try to access protected route:
    • Navigate to http://localhost:5174/dashboard
    • ✅ PASS: Should redirect to landing page (/)
    • ❌ FAIL: If shows dashboard or redirects to /login
  3. Test 3 - Login and then refresh:
    • From landing page, click "Sign In" or go to http://localhost:5174/login
    • Login with valid credentials
    • Should be redirected to /dashboard
    • Refresh the page (F5 or Ctrl+R)
    • ✅ PASS: Should stay on dashboard (authenticated user)
    • ❌ FAIL: If redirected to landing page or login
  4. Test 4 - Logout behavior:
    • While logged in, click logout
    • ✅ PASS: Should redirect to landing page (/)
    • ❌ FAIL: If redirected to /login
