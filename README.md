# 🏥 Elite Tena Healthcare System

## 🚀 Production-Ready Healthcare Management Platform

A comprehensive blockchain-integrated healthcare management system with role-based access control, real-time notifications, and multi-language support.

### ✨ Features

- 🔐 **Secure Authentication**: Email/Password + MetaMask wallet integration
- 👥 **Multi-Role System**: Patient, Doctor, Lab Technician, Pharmacist, Admin
- 📊 **Real-Time Dashboards**: Role-specific dashboards with live data
- 🔔 **Notification System**: Database-backed notifications with real-time updates
- 🌍 **Multi-Language**: English, Amharic, Afan Oromo, Tigrigna
- 📱 **Responsive Design**: Mobile-first, works on all devices
- 🔗 **Blockchain Integration**: Ethereum smart contracts for data integrity
- 📈 **Analytics**: Chart.js powered analytics and reporting

### 🛠️ Tech Stack

**Frontend:**
- React 19 + TypeScript
- Tailwind CSS + Framer Motion
- React Router + React Query
- Web3.js + Ethers.js
- i18next for translations

**Backend:**
- Node.js + Express
- PostgreSQL + Sequelize ORM
- AdminJS for database management
- JWT Authentication
- IPFS for file storage

**Blockchain:**
- Solidity Smart Contracts
- Hardhat Development Environment
- Sepolia Testnet Ready

### 🚀 Quick Start

```bash
# Install dependencies
npm install
cd elite-tena-frontend && npm install
cd ../server && npm install

# Setup environment
cp .env.example .env
cp server/.env.example server/.env

# Start development servers
npm run dev
```
